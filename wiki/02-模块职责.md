## A. 入口与编排

### main.ts — `LocalImagesPlugin`

插件唯一入口类，职责：

- **命令注册**（`onload` L219）：6 个命令 —— 当前笔记本地化（自定义/Obsidian 位置）、批量本地化全部笔记、清理未使用图片、清理未使用附件、清理当前笔记文件夹孤立附件。
- **Ribbon**（`refreshRibbonIcons` L419）：按设置显示/重建"清理未使用图片"按钮。
- **事件接入**：`vault create/delete/rename/modify`（新文件处理、媒体文件夹随笔记删除/重命名同步）与 `editor-paste`（`onPasteFunc` L662，区分文件粘贴与媒体链接文本粘贴）。
- **本地化流程**：`processPage` L550（核心单页处理）、`processActivePage` L610、`processAllPages` L626（带进度 Notice 的全库遍历）。
- **新附件搬迁**：`processMdFilesOnTimer` L919（约 230 行的核心方法，见 [03-关键类与函数](03-关键类与函数.md)）。
- **清理入口**：`clearUnusedAttachments` L432、`removeOrphans` L730。
- **队列/定时器**：`setupQueueInterval` L520、`setupNewMdFilesProcInterval` L1147、`processModifiedQueue` L1160。
- **设置**：`loadSettings` L1179（与 `DEFAULT_SETTINGS` 深合并）、`saveSettings` L1187、`ensureFolderExists` L1199。
- **内部辅助**：嵌入提取（`getEmbeddedAttachmentsFromContent` L83，正文正则补充 metadataCache 之外的嵌入）、引用名集合（`getCurrentNoteAttachmentBaseNames` L142）、MD5 查重（`findDuplicateAttachmentByHash` L182）、时间戳路径生成（`buildTimestampedAttachmentPath` L206）、路径/文件过滤（`ExemplaryOfMD` L901、`ExemplaryOfCANVAS` L906、`ThePathExcluded` L911）。

## B. 基础设施

### config.ts

- `APP_NAME`、`NOTICE_TIMEOUT`（5s）、`TIMEOUT_LIKE_INFINITY`（24h）、`FORBIDDEN_SYMBOLS_FILENAME_PATTERN` 等常量。
- `MD_SEARCH_PATTERN` L16：4 个正则（`file://`、`http(s)`、Base64、兜底），带命名捕获组 `anchor`/`link`。
- `ATT_SIZE_ACHOR`、`MD_LINK`、`HTML_EMBED`、`ANCHOR_S`：辅助解析正则。
- `ISettings` L42：全部设置项的类型定义（通用 8 项、开发者 2 项、本地化 11 项、清理 4 项）；`DEFAULT_SETTINGS` L79 提供默认值。

### utils.ts（通用工具箱）

- **内容替换**：`replaceAsync` L93 —— 收集匹配 → 并发执行异步回调 → 回写，返回 `[新文本, 错误标志, 新文件列表]`。
- **哈希/命名**：`md5Sig` L47（采样 MD5）、`generateTimestampRandomName` L69（`YYYYMMDD-HHmmss-md5前6位`）、`cFileName`/`cleanFileName`（文件名清洗）。
- **下载/解码**：`downloadImage` L215（`requestUrl` + 伪装 UA）、`base64ToBuff` L199。
- **判型**：`getFileExt` L319 + `MAGIC_SIGNATURES` L232 + `ISOBMFF_BRANDS` L246 + `isSvgBuffer` L309。
- **压缩**：`blobToJpegArrayBuffer` L468（canvas 白底重绘 → JPEG/WebP）。
- **路径族**：`pathBasename/pathExtname/pathDirname/pathParse/pathRelative/pathJoin/normalizePath/trimAny/encObsURI`（自实现，兼容桌面/移动端）。
- **通知**：`showBalloon/showStatusBalloon/displayError`；`logError` L44 为空实现（调试输出已关闭）。

### uniqueQueue.ts — `UniqueQueue<T>`

`push(value, attempts)` 去重入队；`iterationQueue()` 用 `reduce` 一次性完成"取出本轮 + 剩余轮次减一回填"，供本地化重试机制使用。

### modal.ts

`ModalW1`（消息 + 取消/确认双按钮，确认执行 `callbackFunc`）、`ModalW2`（消息 + 单按钮）。用于批量处理确认、孤立附件清理确认等。

## C. 本地化流水线

### contentProcessor.ts

- `imageTagProcessor` L25：工厂函数，返回 `processImageTag(match, anchor, link, caption, imgsize)` 异步回调 —— 判定 URL → `AsyncLock` 串行化同名资源 → 三种来源取字节（`data:`/`file:`/网络）→ 大小下限过滤 → PNG 压缩 → `chooseFileName` → `vault.createBinary` → 组装 wiki 或 markdown 新链接（`preserveCaptions` 控制标题、`appendOriginalName` 为 `file:` 来源追加"打开"标签）。
- `getMDir` L219：按 `attachmentSaveLocation`（`inFolderBelow`/`nextToNoteS`/跟随 Obsidian）计算目标目录，支持 `${notename}`、`${unique}` 模板。
- `getRDir` L178：按 `linkPathFormat`（`baseFileName`/`onlyRelative`/`fullDirPath`）生成 wiki 链接路径与 markdown 链接 URI。
- `chooseFileName` L262：扩展名判定 → 未知类型/排除扩展名过滤 → MD5 去重（同名库内文件直接复用）→ 时间戳或 MD5 命名。

## D. 附件清理

### clearUnusedLinkDetector.ts

`getAllLinkMatchesInFile` L12：对任意文本做 wiki `\[\[..\]\]` 与 markdown `\[..](..)` 全量匹配，识别 `#` 嵌入引用（transclusion），跳过 `http` 外链，返回 `LinkMatch[]`（`type/match/linkText/sourceFilePath`）。是"哪些文件被引用"的事实来源，同时服务于清理与孤立附件判断。

### clearUnusedUtils.ts

- `getUnusedAttachments` L20：库内候选（图片集合 或 全部非 `md/canvas`）− 已使用路径集合。
- `getAttachmentPathSetForVault` L51：使用中集合 = `resolvedLinks` + frontmatter（banner 嵌入 / 图片路径字段）+ md 正文链接检测 + canvas 节点（`file` 节点与 `text` 节点内链接）。
- `deleteFilesInTheList` L127：排除文件夹过滤（`fileIsInExcludedFolder` L152，支持子文件夹递归排除）→ `trashFile` → 组装中英文日志。
- `getFormattedDate` L182：日志时间戳。

### clearUnusedModal.ts

`ClearUnusedPreviewModal` L40（标题 + 数量 + 前 80 条路径列表 + 取消/确认删除）；`ClearUnusedLogsModal` L4（按 `</br>` 分行展示日志）。
