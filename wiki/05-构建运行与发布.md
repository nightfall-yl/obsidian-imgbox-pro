# 05 — 构建、运行与发布

## 1. 环境要求

| 项 | 要求 |
| --- | --- |
| Node.js | 18（CI 使用 18.x；本地建议 ≥18） |
| 包管理器 | npm（CI 使用 `npm ci --legacy-peer-deps`） |
| Obsidian | ≥ 1.11.0（设置页依赖 `SettingGroup` API） |
| 平台 | 桌面端全功能；移动端可用但 `file://` 读取与部分交互降级 |

## 2. npm 脚本（package.json）

| 脚本 | 命令 | 说明 |
| --- | --- | --- |
| `npm run dev` | `rollup --config rollup.config.js -w` | 监听模式，输出 `dist/main.js`（含 inline sourcemap），改代码即重建 |
| `npm run build` | `rollup --environment BUILD:production ... && cp manifest.json styles.css dist/ && cp dist/main.js main.js` | 生产构建；产物三件套进 `dist/`，并**复制到根目录 `main.js`**（Obsidian 从插件根目录加载入口） |
| `npm run lint` | `eslint src/**/*.ts` | 代码检查（含 `eslint-plugin-obsidianmd` 官方规则） |
| `npm run version` | `json -I -f manifest.json ...` | 用 npm 包版本同步 `manifest.json` 的 `version` 与 `versions.json` 的 `minAppVersion` 映射 |

## 3. 构建管线（rollup.config.js）

```
src/main.ts
  → rollup-plugin-esbuild (target es2021, sourcemap)
  → @rollup/plugin-node-resolve (browser: true, preferBuiltins: false)
  → @rollup/plugin-json
  → @rollup/plugin-commonjs
  → output: dist/main.js  (format: cjs, exports: default, inline sourcemap)
external: ["obsidian"]        ← 运行时由宿主提供
banner: "THIS IS A GENERATED/BUNDLED FILE BY ROLLUP"
```

生产模式（`BUILD:production`）下排除 sourcemap 的 sources 段。产物体积约 370KB（根目录 `main.js`）。

## 4. 本地开发与调试流程

### 4.1 准备

```bash
npm install
```

### 4.2 方式一：符号链接开发库（推荐）

```bash
# 在本仓库执行 dev 监听
npm run dev

# 将构建产物链接进某个测试库（vault 换成实际路径）
mkdir -p "/path/to/vault/.obsidian/plugins/imgbox-pro"
ln -s "$PWD/main.js" "$PWD/manifest.json" "$PWD/styles.css" \
      /path/to/vault/.obsidian/plugins/imgbox-pro/
```

然后在 Obsidian 中：设置 → 第三方插件 → 关闭安全模式 → 启用 **ImgBox Pro**；改动代码后 `Ctrl/Cmd+P` 执行 **Reload app without saving** 热重载。

### 4.3 方式二：直接拷贝三件套

```bash
npm run build
cp main.js manifest.json styles.css /path/to/vault/.obsidian/plugins/imgbox-pro/
```

### 4.4 调试要点

- 打开开发者工具：`Ctrl/Cmd+Shift+I`；插件 console 日志默认静默（`logError` 为空实现，[utils.ts L44](../src/utils.ts#L44)），需要日志时临时在该函数内加 `console.log`。
- 数据存储：插件设置保存在 `<库>/.obsidian/plugins/imgbox-pro/data.json`（`loadData/saveData`）。
- ESLint：`npm run lint`；规则配置见 [eslint.config.mjs](../eslint.config.mjs)（个别规则如 `editor-drop-paste` 在 `editor-paste` 处理器处有豁免注释）。
- TypeScript 仅做类型检查（构建走 esbuild，不做 tsc emit）；`tsconfig.json` 开启 `noImplicitAny`。

## 5. 版本与发布

### 5.1 版本号三处同步

| 文件 | 字段 |
| --- | --- |
| `package.json` | `version`（源头，`npm version x.y.z` 自动改） |
| `manifest.json` | `version` + `minAppVersion`（`npm run version` 同步） |
| `versions.json` | `"插件版本": "最低 Obsidian 版本"` 映射（`npm run version` 同步） |

当前：插件 `26.0.5`，`minAppVersion 1.11.0`。

### 5.2 发布流程

1. 更新 [CHANGELOG.md](../CHANGELOG.md)（Keep a Changelog 中文格式）。
2. `npm version <tag>` 并推送 tag —— GitHub Actions [release.yml](../.github/workflows/release.yml) 被触发：

```yaml
on: push tags "*"
步骤：checkout → setup-node 18 → npm ci --legacy-peer-deps
     → npm run build
     → actions/attest-build-provenance（对 dist 三件套生成构建证明）
     → softprops/action-gh-release 上传 dist/main.js、dist/manifest.json、dist/styles.css
```

3. Release 附件即为社区插件市场所需的三个文件。

## 6. 运行时行为速查（用户视角）

| 入口 | 触发结果 |
| --- | --- |
| 命令：本地化当前笔记附件（自定义位置/Obsidian 位置） | `processActivePage(false/true)` |
| 命令：批量本地化所有笔记 | `ModalW1` 确认 → `processAllPages` 全库遍历（进度 Notice） |
| 命令：清理库中未引用的图片/附件 | `clearUnusedAttachments("image"/"all")` 预览确认后删除 |
| 命令：清理当前笔记文件夹孤立附件 | 仅"笔记旁 + `${notename}`"设置下可用（`removeOrphans`） |
| Ribbon：清理未使用图片（中/英文案） | 等价于 `clearUnusedAttachments("image")` |
| 自动处理：粘贴/新建（可关，间隔 3–3600s） | 队列 + 定时器驱动本地化与新附件搬迁 |
| 右键菜单：库内图片/iframe/video/audio | 复制、系统打开、导航定位、重命名、删除文件及链接 |
| 右键菜单：外部 http 图片 | 复制图片/链接、Markdown 链接、外部浏览器、删链接（源码模式） |
| 图片跳转原笔记 | 文件菜单"跳转到原笔记"（有引用时）或导航定位高亮 |

## 7. 安装（最终用户）

1. 从 [Releases](https://github.com/nightfall-yl/obsidian-imgbox-pro/releases) 下载 `main.js`、`manifest.json`、`styles.css`；
2. 放入 `<库>/.obsidian/plugins/imgbox-pro/`；
3. 重启 Obsidian → 设置 → 第三方插件 → 启用 ImgBox Pro。

> 批量处理/清理/链接改写前建议先备份库。
