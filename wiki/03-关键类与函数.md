## 2. 关键函数

### 2.1 本地化流水线

#### `replaceAsync(str, regex[], asyncFn)` — [utils.ts L93](../src/utils.ts#L93)

```ts
async function replaceAsync(
  str: string,
  regex: RegExp[],
  asyncFn: (key, anchor, link, caption, imgsize) => Promise<[string, string, string] | null | string>
): Promise<[string, boolean, string[]]>
```

行为：
1. 用每个正则 `matchAll` 收集匹配到 `dictPatt`（键为去除括号的匹配原文，天然去重）。
2. 对每个条目并发调用 `asyncFn`，`Promise.all` 等待。
3. 逐个 `str.replaceAll(原匹配, 新标签 + 附加标签)`；任一结果为 `null` 置 `errorflag=true`。
4. 返回 `[新文本, errorflag, 新文件路径列表]`。

> 注意：并发处理但串行回写，且匹配去重避免了同一链接重复下载。

#### `imageTagProcessor(app, noteFile, settings, defaultdir)` — [contentProcessor.ts L25](../src/contentProcessor.ts#L25)

工厂函数，返回 `processImageTag(match, anchor, link, caption, imgsize)`。单张图片的完整处理：

1. `isUrl(link)` 过滤（`file:`/`data:`/`http(s)` 均可通过 `new URL`）。
2. `AsyncLock` 按 match 串行化，防并发写同名文件。
3. `getMDir` 计算目标目录并 `ensureFolderExists`。
4. 取字节：`data:` → `base64ToBuff`；`file:` → 桌面端 `requestUrl`（移动端不支持返回 `null`）；网络 → `downloadImage` × `downloadRetryCount` 重试。
5. 大小下限过滤（`minFileSizeKB`）。
6. PNG 且开启压缩 → `blobToJpegArrayBuffer`（JPEG/WebP）。
7. `chooseFileName` → `vault.createBinary`。
8. `getRDir` 生成链接 → 按 `useMarkdownLinks` 输出 `![[path|caption]]` 或 `![anchor](uri caption)`；`appendOriginalName` 且 `file:` 来源追加 `Open:` 链接行。
9. 失败返回 `null`（触发上层 errorflag），"File already exists." 之外异常上抛。

#### `getMDir(app, noteFile, settings, defaultdir?, unique?)` — [contentProcessor.ts L219](../src/contentProcessor.ts#L219)

| `attachmentSaveLocation` | 目录规则 |
| --- | --- |
| `inFolderBelow` | `mediaFolderPath`，替换 `${notename}` / `${unique}` |
| `nextToNoteS` | `pathJoin(笔记目录, mediaFolderPath)`，替换模板 |
| 其他（跟随 Obsidian） | 读 `vault.getConfig("attachmentFolderPath")`：`"/"` → 根；`"./"` → 笔记目录；`"./xxx"` → 笔记目录 + xxx；否则原值 |

#### `getRDir(noteFile, settings, fileName, link?)` — [contentProcessor.ts L178](../src/contentProcessor.ts#L178)

| `linkPathFormat` | wiki 路径 | markdown 路径 |
| --- | --- | --- |
| `baseFileName` | `名称.扩展名` | 同左 |
| `onlyRelative` | 相对笔记路径 | `encodeURI(相对路径)` |
| `fullDirPath` | 完整库内路径 | `encodeURI(完整路径)` |

返回 `[pathWiki, pathMd, {lnkurid, pathuri, ...}]`，第三项供 `appendOriginalName` 生成 `Open:` 链接。

#### `chooseFileName(app, adapter, dir, link, contentData, settings)` — [contentProcessor.ts L262](../src/contentProcessor.ts#L262)

扩展名判定 → `unknown` 且未允许则放弃 → 排除扩展名过滤 → `md5Sig` 指纹：

- **时间戳命名开启**：扫描目录内文件 MD5 命中则直接复用（`needWrite=false`）；否则 `generateTimestampRandomName` 循环探测至路径唯一。
- **关闭**：`md5.ext` 命名；已存在且 MD5 相同 → 复用；不同 → 随机名兜底。

### 2.3 清理流水线

#### `getUnusedAttachments(app, type)` — [clearUnusedUtils.ts L20](../src/clearUnusedUtils.ts#L20)

```
候选 = getAttachmentsInVault(app, type)     // "image" 仅图片扩展名；"all" 为全部非 md/canvas
已用 = getAttachmentPathSetForVault(app)    // resolvedLinks + frontmatter + 链接检测 + canvas
未用 = 候选 − 已用
```

`getAttachmentPathSetForVault`（L51）的四个来源：
1. `metadataCache.resolvedLinks` 中所有非 `.md` 目标；
2. md frontmatter 字符串值：`!\[\[..\]\]` banner 与图片路径正则；
3. 每篇 md 的 `getAllLinkMatchesInFile`；
4. canvas JSON：`file` 节点 + `text` 节点内链接检测。

#### `getAllLinkMatchesInFile(mdFile, app, fileText?)` — [clearUnusedLinkDetector.ts L12](../src/clearUnusedLinkDetector.ts#L12)

对文本做 wiki/md 两类正则全量扫描，`#` 命中视为嵌入引用并提取 `#` 前文件名，`http` 开头跳过；`linkText` 优先取 `getFirstLinkpathDest` 解析后的真实路径。返回 `LinkMatch { type, match, linkText, sourceFilePath }`。

#### `deleteFilesInTheList(fileList, settings, app)` — [clearUnusedUtils.ts L127](../src/clearUnusedUtils.ts#L127)

跳过 `fileIsInExcludedFolder` 命中的文件（`excludedFolders` 按行/逗号拆分；`excludeSubfolders` 开启时用 `^path(/.*)?$` 前缀匹配）→ 其余 `trashFile` → 返回 `{ deletedImages, textToView }`。

### 2.4 预览交互

- 表格（`/^\s*\|/`）/ Callout（`/^>/`）：从目标行向上下双向扩展扫描，整块中唯一匹配才删。

#### `updateInternalLink / updateExternalLink / updateGroupedLink` — [previewLink.ts L27 / L79 / L136]

#### `locateFileInExplorer(...)` — [previewExplorer.ts L92](../src/previewExplorer.ts#L92)

#### `onElement(el, event, selector, listener, options?)` — [previewHelpers.ts L199](../src/previewHelpers.ts#L199)

## 4. 典型调用链速查

```
[手动本地化]   命令 → processActivePage → processPage → replaceAsync → imageTagProcessor
               → getMDir → downloadImage/base64ToBuff → getFileExt → blobToJpegArrayBuffer
               → chooseFileName → vault.createBinary → getRDir → vault.modify

[自动搬迁]     vault.create → onFCreateFunc → newfCreated/noteModified → setupNewMdFilesProcInterval
               → processMdFilesOnTimer → getMDir → findDuplicateAttachmentByHash /
               buildTimestampedAttachmentPath → adapter.rename/writeBinary → getRDir → vault.modify

[全库清理]     Ribbon/命令 → clearUnusedAttachments → getUnusedAttachments
               → getAllLinkMatchesInFile → ClearUnusedPreviewModal → deleteFilesInTheList
               → trashFile → ClearUnusedLogsModal

[右键删除]     contextmenu → PreviewFeature.onRightClickMenu → addMenuExtendedSourceMode
               → handlerDelFileNew → checkReferenceInfo → deleteCurTargetLink(getEditorView)
               → pureClearAttachment → deleteFile → trashFile

[调宽同步]     拖拽 resize → updateInternalLink/updateExternalLink → matchLineWith*Link
               → editorView.dispatch
```
